Short-term context
Working memory lives in the LangGraph thread. A new conversation starts a new thread, while this student’s long-term records remain.
Long-term learning
Mem0 stores and retrieves facts. Semantic, episodic and procedural labels are transparent application heuristics, not separate Mem0 engines.
Honest activity
Cards show stored contents. READ, WRITE, ADD, UPDATE and ERROR reflect actual operations. The model’s weights are never inspected or changed.
Future intentions
Prospective records are pending tasks, not scheduled notifications. You can mark them complete. A Python-version question triggers a live external lookup.
